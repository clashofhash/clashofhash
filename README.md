Created to get more sparks, maybe someone else can use it
The executable is compiled with g++.

 How to use:
 'di3 unpack file1' will analyze the file and create a file1.txt that contains the text content
	'di3 pack file2' will use te file2 content to createa savegame named 'file.save' . You will have to rename the 'file.save' and put it in your savegames folder to be loaded by DI

 This project was made ultrafast, so there is limited error checking. If something goes wrong it will just exit. As far as i tested i didnt find any memory leaks.

 If you find a problem, i m not sure i will be able to respond (this is not my full time work, it is just a sub-sub-project i took for my kid to avoid grinding for sparks)..


This https://github.com/themadgoblin/DI3SaveGameEditor appears to have more progress made but it relies on python.
